## Project Overview

A **Supplier Hub** platform for cosmetic raw materials compliance. Two portals:

1. **Supplier Portal** — External factories self-register with materials and upload compliance documents (SDS, TDS, CoA, REACH/RoHS). Purple gradient theme. 4-step wizard UX.
2. **Management Portal** — Internal admin dashboard for user/department/supplier management. Dark navy theme.

Built with **FastAPI** (Python) backend, vanilla JS/HTML frontend, **PostgreSQL** (both production and local dev). SQLite data preserved for reference in `backend/db/supplier_hub.db`.

## Registration API Endpoints (`/api/registration/`)

| Method | Path | Purpose |
|--------|------|---------|
| GET | `/countries` | List all country names |
| GET | `/metadata/lookup` | Countries, SDS languages, physical states, supply types |
| GET | `/draft` | Load current supplier's draft (nested materials + documents) |
| POST | `/step1-profile` | Save supplier profile (FormData) |
| POST | `/step2-materials` | Save material identifiers (JSON payload) |
| POST | `/step3-documents` | Bulk document upload with metadata |
| POST | `/step3-documents/single` | Single document upload with type-specific metadata |
| POST | `/submit` | Validate and submit (blocks only if SDS > 3 years) |
| GET | `/document/{id}/download` | Download uploaded file |
| DELETE | `/document/{id}` | Remove document + file from disk |
| GET | `/manufactures` | List registered manufactures |
| POST | `/manufactures` | Create manufacture |
| PUT | `/manufactures/{id}` | Update manufacture |
| DELETE | `/manufactures/{id}` | Delete manufacture (fails if materials exist) |
| PUT | `/material/{id}/deactivate` | Soft-deactivate material (sets is_active=False) |
| PUT | `/material/{id}/reactivate` | Reactivate material (sets is_active=True) |
| DELETE | `/material/{id}` | Deactivate material + orphan its documents |

## How to Run

```bash

docker compose up -d db

# Run migrations and start server
python backend/migrate_sqlite_to_pg.py
python backend/main.py
```
